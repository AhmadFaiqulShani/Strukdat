Berikut tahapan algoritma selection sort (ascending order):¶

  1. Algoritma ini dimulai dari indeks awal sampai dengan indeks akhir data
  2. Cari data dengan nilai paling minimal (dari indeks awal sampai dengan indeks akhir) melalui proses perbandingan
  3. Letakkan data minimal ini di indeks awal
  4. Ulangi lagi proses pencarian data paling minimal (dari indeks awal+1 sampai dengan indeks akhir, karena indeks awal sudah terisi data yang tepat).
  5. Letakkan data ini pada indeks awal+1
  6. Ulangi lagi proses pencarian data paling minimal (dari indeks awal+2 sampai dengan akhir) dan letakkan data ini pada indeks awal+2, dst.

Langkah 3: Pindahkan nilai terendah, yaitu 3, ke bagian depan array.

[ 3, 7, 12, 9, 11]

[ 3, 7, 12, 9, 11]

[ 3, 7, 12, 9, 11]

[ 3, 7, 9, 12, 11]

Penjelasan Manual: Apa yang Terjadi?¶

Kita harus memahami apa yang terjadi di atas untuk sepenuhnya memahami algoritma tersebut, sehingga kita dapat mengimplementasikan algoritma tersebut dalam bahasa pemrograman.

Bisakah Anda melihat apa yang terjadi pada nilai terendah, yaitu 3? Pada langkah 3, nilai tersebut telah dipindahkan ke awal array, tempat seharusnya berada, tetapi pada langkah tersebut sisa array tetap tidak terurut.

Jadi, algoritma Selection Sort harus menjalankan proses pada array berulang kali, setiap kali nilai terendah berikutnya dipindahkan ke depan bagian array yang belum diurutkan, ke posisi yang benar. Pengurutan berlanjut hingga nilai tertinggi 12 tersisa di akhir array. Ini berarti kita perlu menjalankan proses pada array sebanyak 4 kali untuk mengurutkan array yang berisi 5 nilai.

Dan setiap kali algoritma dijalankan melalui array, bagian array yang belum diurutkan akan menjadi lebih pendek.

Sekarang kita akan menggunakan apa yang telah kita pelajari untuk mengimplementasikan algoritma Selection Sort dalam bahasa pemrograman.

Iterasi pertama digunakan untuk menempatkan data atau menukar data, sehingga data dengan nilai minimal, akan menempati indeks-indeks awal. Sedangkan iterasi kedua (iterasi dalam), digunakan untuk mencari nilai minimal.

def selectionSort(listData):

    print('Algoritma Selection Sort konvensional')
    print('Data Awal=',listData)
    for outIter in range(len(listData)-1):
        minIndex=outIter
        for i in range(outIter+1,len(listData)):
            if listData[i]<listData[minIndex]:
                minIndex=i
        temp=listData[outIter]
        listData[outIter]=listData[minIndex]
        listData[minIndex]=temp
        print('Iterasi ke-',outIter+1,':',listData)
    print('Data Urut=',listData)

Selection Sort Shifting Problem¶

Algoritma Selection Sort dapat ditingkatkan sedikit lagi.

Pada kode di atas, elemen dengan nilai terendah dihapus, lalu disisipkan di bagian depan array.

Setiap kali elemen array dengan nilai terendah berikutnya dihapus, semua elemen berikutnya harus digeser satu tempat ke bawah untuk mengimbangi penghapusan tersebut.

Operasi pergeseran ini memakan banyak waktu, dan kita bahkan belum selesai! Setelah nilai terendah (5) ditemukan dan dihapus, nilai tersebut dimasukkan di awal array, menyebabkan semua nilai berikutnya bergeser satu posisi ke atas untuk memberi ruang bagi nilai baru, seperti yang ditunjukkan pada gambar di bawah ini.

Catatan: Anda tidak akan melihat operasi pergeseran ini terjadi dalam kode jika Anda menggunakan bahasa pemrograman tingkat tinggi seperti Python atau Java, tetapi operasi pergeseran tetap terjadi di latar belakang. Operasi pergeseran tersebut membutuhkan waktu tambahan bagi komputer untuk melakukannya, yang dapat menjadi masalah.

Solusi: Tukar Nilai!¶

Alih-alih semua pergeseran, tukar nilai terendah (5) dengan nilai pertama (64) seperti di bawah ini.

Kita dapat menukar nilai seperti yang ditunjukkan pada gambar di atas karena nilai terendah akan berada di posisi yang benar, dan tidak masalah di mana kita meletakkan nilai lain yang kita tukar, karena nilai tersebut belum diurutkan.

my_array = [64, 34, 25, 12, 22, 11, 90, 5]

n = len(my_array)
for i in range(n):
    min_index = i
    for j in range(i+1, n):
        if my_array[j] < my_array[min_index]:
            min_index = j   
    my_array[i], my_array[min_index] = my_array[min_index], my_array[i]

Insertion Sort (Pengurutan Sisipan)¶

Algoritma Insertion Sort menggunakan satu bagian dari array untuk menyimpan nilai-nilai yang sudah diurutkan, dan bagian lain dari array untuk menyimpan nilai-nilai yang belum diurutkan.

Algoritma ini mengambil satu nilai pada satu waktu dari bagian array yang belum diurutkan dan menempatkannya di tempat yang tepat di bagian array yang sudah diurutkan, hingga array tersebut menjadi terurut.

Cara kerjanya:

  1. Ambil nilai pertama dari bagian array yang belum diurutkan.
  2. Pindahkan nilai tersebut ke tempat yang tepat di bagian array yang sudah diurutkan.
  3. Lakukan penelusuran ulang pada bagian array yang belum diurutkan sebanyak jumlah nilai yang ada.

Panduan Langkah demi Langkah¶

Sebelum kita mengimplementasikan algoritma Insertion Sort dalam bahasa pemrograman, mari kita jalankan secara manual sebuah array pendek, hanya untuk mendapatkan gambaran umumnya.

Langkah 1: Kita mulai dengan array yang belum diurutkan.

[ 7, 12, 9, 11, 3]

Langkah 2: Kita dapat menganggap nilai pertama sebagai bagian array yang sudah diurutkan pada awalnya. Jika hanya satu nilai, pasti sudah diurutkan, bukan?

[ 7, 12, 9, 11, 3]

Langkah 3: Nilai berikutnya, 12, sekarang harus dipindahkan ke posisi yang benar di bagian array yang sudah diurutkan. Tetapi 12 lebih tinggi dari 7, jadi 12 sudah berada di posisi yang benar.

[ 7, 12, 9, 11, 3]

Langkah 4: Pertimbangkan nilai berikutnya, yaitu 9.

[ 7, 12, 9, 11, 3]

Langkah 5: Nilai 9 sekarang harus dipindahkan ke posisi yang benar di dalam bagian array yang sudah diurutkan, jadi kita pindahkan 9 di antara 7 dan 12.

[ 7, 9, 12, 11, 3]

Langkah 6: Nilai selanjutnya adalah 11.

[ 7, 9, 12, > 11, 3]

Langkah 7: Kita pindahkan ke antara posisi 9 dan 12 di bagian array yang sudah diurutkan.

[ 7, 9, 11, 12, 3]

Langkah 8: Nilai terakhir yang perlu dimasukkan ke posisi yang tepat adalah 3.

[ 7, 9, 11, 12, 3]

Langkah 9: Kita memasukkan angka 3 di depan semua nilai lainnya karena itu adalah nilai terendah.

[ 3,7, 9, 11, 12]

Akhirnya, array tersebut telah diurutkan.

Pengurutan Sisipan [7 ,12 ,9 ,11 ,3]

Pada algoritma insertion sort, diasumsikan bahwa sebagian data sudah dalam keadaan terurut (pada posisi sebelah kiri dari data list), sehingga data berikutnya akan dibandingkan dengan data yang sudah dalam keadaan terurut ini, dan disisipkan (insertion) pada bagian data yang sudah terurut tersebut. Dengan konsep seperti ini, posisi sebelah kiri dari list data (sebelum ada data baru yang akan disisipkan), selalu dalam keadaan terurut.

Berikut algoritma Insertion Sort :

  1. Asumsi bahwa data ke-1 sampai dengan (n/2) sudah dalam keadaan terurut
  2. Sisipkan data ke (n/2)+1 atau key ke dalam bagian data yang sudah dalam keadaan terurut, dengan cara:
  3. lakukan perbandingan data antara key dengan data pada indeks sebelumnya, jika key bernilai lebih kecil, maka lakukan pergeseran posisi data.
  4. lakukan terus perbandingan data key ini dengan data pada indeks sebelumnya, sampai data key tidak lebih kecil lagi atau atau sampai dengan data pada posisi pertama.

Berikut code untuk pengurutan dengan menggunakan algoritma Insertion Sort. Iterasi dalam, menggunakan iterasi while, karena iterasi akan berhenti atau tidak dikerjakan, ketika nilai pada key lebih dari data terakhir yang akan dibandingkan.

def insertionSort(listData):
    
    for outIter in range(1,len(listData)):
        print(listData)
        key=listData[outIter]
        ind=outIter
        while (ind>0 and listData[ind-1]>key):
            listData[ind]=listData[ind-1]
            ind=ind-1
            print('inner=',listData)
        listData[ind]=key
    print('sortedData=',listData)

(Insertion Sort Improvement) Peningkatan Pengurutan Sisipan¶

Algoritma Insertion Sort masih bisa ditingkatkan sedikit lagi.

Cara kode di atas pertama-tama menghapus suatu nilai lalu memasukkannya ke tempat lain sangat intuitif. Ini mirip dengan cara Anda melakukan Insertion Sort secara fisik dengan setumpuk kartu, misalnya. Jika kartu bernilai rendah diurutkan ke kiri, Anda mengambil kartu baru yang belum diurutkan, dan memasukkannya ke tempat yang tepat di antara kartu-kartu lain yang sudah diurutkan.

Masalah dengan cara pemrograman ini adalah ketika menghapus suatu nilai dari array, semua elemen di atasnya harus digeser satu indeks ke bawah:

Dan ketika memasukkan kembali nilai yang dihapus ke dalam array, ada juga banyak operasi pergeseran yang harus dilakukan: semua elemen berikutnya harus bergeser satu posisi ke atas untuk memberi tempat bagi nilai yang dimasukkan:

Operasi pergeseran ini dapat memakan banyak waktu, terutama untuk array dengan banyak elemen.

Kita dapat menghindari sebagian besar operasi pergeseran ini dengan hanya menggeser nilai-nilai yang diperlukan:

def optimized_bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        swapped = False
        for j in range(0, n - i - 1):
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
                swapped = True
        if not swapped:
            break
    return arr

def selection_sort_desc(arr):
    n = len(arr)
    for i in range(n):
        max_idx = i
        for j in range(i + 1, n):
            if arr[j] > arr[max_idx]:
                max_idx = j
        arr[i], arr[max_idx] = arr[max_idx], arr[i]
    return arr

def insertion_sort_length(arr):
    for i in range(1, len(arr)):
        key = arr[i]
        j = i - 1
        while j >= 0 and len(key) < len(arr[j]):
            arr[j + 1] = arr[j]
            j -= 1
        arr[j + 1] = key
    return arr

def bubble_sort_swaps(arr):
    n = len(arr)
    swaps = 0
    arr_copy = arr.copy()
    for i in range(n):
        for j in range(0, n - i - 1):
            if arr_copy[j] > arr_copy[j + 1]:
                arr_copy[j], arr_copy[j + 1] = arr_copy[j + 1], arr_copy[j]
                swaps += 1
    return swaps

def selection_sort_swaps(arr):
    n = len(arr)
    swaps = 0
    arr_copy = arr.copy()
    for i in range(n):
        min_idx = i
        for j in range(i + 1, n):
            if arr_copy[j] < arr_copy[min_idx]:
                min_idx = j
        if min_idx != i:
            arr_copy[i], arr_copy[min_idx] = arr_copy[min_idx], arr_copy[i]
            swaps += 1
    return swaps
