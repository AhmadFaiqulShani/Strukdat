Algoritma Selection Sort¶

Algoritma selection sort memiliki waktu komputasi yang lebih cepat dibandingkan dengan algoritma bubble sort. Hal ini dikarenakan terjadi reduksi waktu pada saat proses pertukaran data. Jika algoritma bubble sort, pada setiap iterasi,setiap dua data yang berdekatan akan dibandingkan, dan akan dilakukan pertukaran data jika syarat memenuhi. Maka pada algoritma selection sort tidak akan melakukan dua proses ini (perbandingan dan pertukaran) pada satu waktu, akan tetapi, pada algoritma selection sort, akan dicari data yang memenuhi syarat terlebih dahulu (perbandingan data), kemudian data yang terpilih ini ini akan diletakkan pada indeks data yang tepat. Oleh karena itu algoritma ini dinamakan selection (pemilihan data).

Berikut tahapan algoritma selection sort (ascending order):¶

  1. Algoritma ini dimulai dari indeks awal sampai dengan indeks akhir data
  2. Cari data dengan nilai paling minimal (dari indeks awal sampai dengan indeks akhir) melalui proses perbandingan
  3. Letakkan data minimal ini di indeks awal
  4. Ulangi lagi proses pencarian data paling minimal (dari indeks awal+1 sampai dengan indeks akhir, karena indeks awal sudah terisi data yang tepat).
  5. Letakkan data ini pada indeks awal+1
  6. Ulangi lagi proses pencarian data paling minimal (dari indeks awal+2 sampai dengan akhir) dan letakkan data ini pada indeks awal+2, dst.

Panduan Langkah demi Langkah¶

Sebelum kita mengimplementasikan algoritma Selection Sort dalam bahasa pemrograman, mari kita jalankan secara manual satu kali saja pada sebuah array pendek, hanya untuk mendapatkan gambaran dasarnya.

Langkah 1: Kita mulai dengan array yang belum diurutkan.

[ 7, 12, 9, 11, 3]

Langkah 2: Telusuri array, satu nilai per satu. Nilai mana yang terendah? 3, kan?

[ 7, 12, 9, 11, 3]

Langkah 3: Pindahkan nilai terendah, yaitu 3, ke bagian depan array.

[ 3, 7, 12, 9, 11]

Langkah 4: Periksa nilai-nilai lainnya, dimulai dari 7. 7 adalah nilai terendah, dan sudah berada di bagian depan array, jadi kita tidak perlu memindahkannya.

[ 3, 7, 12, 9, 11]

Langkah 5: Periksa sisa array: 12, 9, dan 11. 9 adalah nilai terendah.

[ 3, 7, 12, 9, 11]

Langkah 6: Pindahkan 9 ke depan.

[ 3, 7, 9, 12, 11]

Langkah 7: Melihat angka 12 dan 11, 11 adalah yang terendah.

[ 3, 7, 9, 12, 11]

Langkah 8: Pindahkan ke depan.

[ 3, 7, 9, 11, 12]

Akhirnya, array tersebut telah diurutkan.

Penjelasan Manual: Apa yang Terjadi?¶

Kita harus memahami apa yang terjadi di atas untuk sepenuhnya memahami algoritma tersebut, sehingga kita dapat mengimplementasikan algoritma tersebut dalam bahasa pemrograman.

Bisakah Anda melihat apa yang terjadi pada nilai terendah, yaitu 3? Pada langkah 3, nilai tersebut telah dipindahkan ke awal array, tempat seharusnya berada, tetapi pada langkah tersebut sisa array tetap tidak terurut.

Jadi, algoritma Selection Sort harus menjalankan proses pada array berulang kali, setiap kali nilai terendah berikutnya dipindahkan ke depan bagian array yang belum diurutkan, ke posisi yang benar. Pengurutan berlanjut hingga nilai tertinggi 12 tersisa di akhir array. Ini berarti kita perlu menjalankan proses pada array sebanyak 4 kali untuk mengurutkan array yang berisi 5 nilai.

Dan setiap kali algoritma dijalankan melalui array, bagian array yang belum diurutkan akan menjadi lebih pendek.

Sekarang kita akan menggunakan apa yang telah kita pelajari untuk mengimplementasikan algoritma Selection Sort dalam bahasa pemrograman.

def selectionSort(listData):

    print('Algoritma Selection Sort konvensional')
    print('Data Awal=',listData)
    for outIter in range(len(listData)-1):
        minIndex=outIter
        for i in range(outIter+1,len(listData)):
            if listData[i]<listData[minIndex]:
                minIndex=i
        temp=listData[outIter]
        listData[outIter]=listData[minIndex]
        listData[minIndex]=temp
        print('Iterasi ke-',outIter+1,':',listData)
    print('Data Urut=',listData)

Selection Sort Shifting Problem¶

Algoritma Selection Sort dapat ditingkatkan sedikit lagi.

Pada kode di atas, elemen dengan nilai terendah dihapus, lalu disisipkan di bagian depan array.

Setiap kali elemen array dengan nilai terendah berikutnya dihapus, semua elemen berikutnya harus digeser satu tempat ke bawah untuk mengimbangi penghapusan tersebut.

Operasi pergeseran ini memakan banyak waktu, dan kita bahkan belum selesai! Setelah nilai terendah (5) ditemukan dan dihapus, nilai tersebut dimasukkan di awal array, menyebabkan semua nilai berikutnya bergeser satu posisi ke atas untuk memberi ruang bagi nilai baru, seperti yang ditunjukkan pada gambar di bawah ini.

Catatan: Anda tidak akan melihat operasi pergeseran ini terjadi dalam kode jika Anda menggunakan bahasa pemrograman tingkat tinggi seperti Python atau Java, tetapi operasi pergeseran tetap terjadi di latar belakang. Operasi pergeseran tersebut membutuhkan waktu tambahan bagi komputer untuk melakukannya, yang dapat menjadi masalah.

Solusi: Tukar Nilai!¶

Alih-alih semua pergeseran, tukar nilai terendah (5) dengan nilai pertama (64) seperti di bawah ini.

Kita dapat menukar nilai seperti yang ditunjukkan pada gambar di atas karena nilai terendah akan berada di posisi yang benar, dan tidak masalah di mana kita meletakkan nilai lain yang kita tukar, karena nilai tersebut belum diurutkan.

Berikut adalah implementasi dari Selection Sort yang disempurnakan, menggunakan pertukaran (swapping):

    min_index = i
    for j in range(i+1, n):
        if my_array[j] < my_array[min_index]:
            min_index = j

def optimized_bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        swapped = False
        for j in range(0, n - i - 1):
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
                swapped = True
        if not swapped:
            break
    return arr

def selection_sort_desc(arr):
    n = len(arr)
    for i in range(n):
        max_idx = i
        for j in range(i + 1, n):
            if arr[j] > arr[max_idx]:
                max_idx = j
        arr[i], arr[max_idx] = arr[max_idx], arr[i]
    return arr

def insertion_sort_length(arr):
    for i in range(1, len(arr)):
        key = arr[i]
        j = i - 1
        while j >= 0 and len(key) < len(arr[j]):
            arr[j + 1] = arr[j]
            j -= 1
        arr[j + 1] = key
    return arr

def bubble_sort_swaps(arr):
    n = len(arr)
    swaps = 0
    arr_copy = arr.copy()
    for i in range(n):
        for j in range(0, n - i - 1):
            if arr_copy[j] > arr_copy[j + 1]:
                arr_copy[j], arr_copy[j + 1] = arr_copy[j + 1], arr_copy[j]
                swaps += 1
    return swaps

def selection_sort_swaps(arr):
    n = len(arr)
    swaps = 0
    arr_copy = arr.copy()
    for i in range(n):
        min_idx = i
        for j in range(i + 1, n):
            if arr_copy[j] < arr_copy[min_idx]:
                min_idx = j
        if min_idx != i:
            arr_copy[i], arr_copy[min_idx] = arr_copy[min_idx], arr_copy[i]
            swaps += 1
    return swaps

def sort_siswa(arr):
    n = len(arr)
    for i in range(1, n):
        key = arr[i]
        j = i - 1
