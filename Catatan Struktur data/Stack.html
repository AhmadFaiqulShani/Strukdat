Stack (Tumpukan)¶

Stack adalah struktur data yang dapat menampung banyak elemen, dan elemen terakhir yang ditambahkan adalah elemen pertama yang dihapus. Tumpukan (stack): kumpulan barang yang terurut di mana penambahan barang baru dan penghapusan barang yang sudah ada selalu terjadi di ujung yang sama.

Ujung ini biasanya disebut sebagai “top.” atau atas ssedangkan Ujung yang berlawanan dengan atas dikenal sebagai “base.” atau dasar.

Seperti tumpukan pancake, pancake ditambahkan dan dikeluarkan dari atas. Jadi, ketika mengeluarkan pancake, itu selalu pancake terakhir yang Anda tambahkan. Cara mengatur elemen seperti ini disebut LIFO: Last In First Out (Terakhir Masuk, Pertama Keluar).

Stack adalah struktur data linier yang mengikuti prinsip Last-In-First-Out (LIFO). Bayangkan seperti tumpukan pancake - Anda hanya bisa menambah atau mengurangi pancake dari bagian atas. Prinsip pemesanan ini terkadang disebut LIFO/FILO.

Operasi dasar yang dapat kita lakukan pada sebuah stack adalah:

  • Push: Menambahkan elemen baru ke dalam tumpukan.
  • Pop: Menghapus dan mengembalikan elemen teratas dari tumpukan.
  • Peek: Mengembalikan elemen teratas (terakhir) pada tumpukan.
  • isEmpty: Memeriksa apakah tumpukan kosong.
  • Ukuran: Menemukan jumlah elemen dalam tumpukan.

Stack dapat diimplementasikan dengan menggunakan array atau linked list.

Stack dapat digunakan untuk mengimplementasikan mekanisme undo, untuk kembali ke keadaan sebelumnya, untuk membuat algoritma pencarian mendalam (depth-first search) dalam graf, atau untuk penelusuran balik (backtracking).

Untuk list (dan array) Python, sebuah tumpukan dapat terlihat dan berperilaku seperti ini:

x = [5, 6, 2, 9, 3, 8, 4, 2]

class Tumpukan:
    def __init__(self):
        self.data = []  

    def tambah(self, nilai):
        self.data.append(nilai)

    def ambil(self):
        if len(self.data) == 0:
            return "Tumpukan kosong"
        return self.data.pop()

    def lihat(self):
        if len(self.data) == 0:
            return "Tumpukan kosong"
        return self.data[-1]

    def kosong(self):
        return len(self.data) == 0

    def jumlah(self):
        return len(self.data)

tumpukan_saya.tambah("F")
tumpukan_saya.tambah("a")
tumpukan_saya.tambah("i")
tumpukan_saya.tambah("q")

print("Data diambil:", tumpukan_saya.ambil())
print("Isi setelah diambil:", tumpukan_saya.data)
print("Data teratas:", tumpukan_saya.lihat())
print("Apakah kosong:", tumpukan_saya.kosong())

Implementasi Stack menggunakan Linked List¶

Sebuah linked list terdiri dari node yang berisi data tertentu, dan sebuah pointer ke node berikutnya.

Alasan untuk mengimplementasikan stack menggunakan list/array:

Efisien Memori: Elemen array tidak menyimpan alamat elemen berikutnya seperti halnya node pada linked list. Lebih mudah diimplementasikan dan dipahami: Menggunakan array untuk mengimplementasikan stack membutuhkan lebih sedikit kode daripada menggunakan linked list, dan karena alasan ini biasanya juga lebih mudah dipahami. Alasan mengapa array tidak digunakan untuk mengimplementasikan stack:

Ukuran tetap: Sebuah array menempati bagian memori yang tetap. Ini berarti bahwa array tersebut dapat menggunakan lebih banyak memori daripada yang dibutuhkan, atau jika array penuh, array tersebut tidak dapat menampung elemen lagi.

Salah satu keuntungan besar menggunakan linked list adalah node disimpan di mana pun ada ruang kosong di memori, node tidak perlu disimpan berdekatan satu sama lain seperti elemen yang disimpan dalam array. Keuntungan lain dari linked list adalah ketika menambahkan atau menghapus node, node lain dalam list tidak perlu digeser.

class Node:
    def __init__(self, data):
        self.data = data
        self.berikutnya = None

class Stack:
    def __init__(self):
        self.atas = None   

    def push(self, data):
        node_baru = Node(data)
        node_baru.berikutnya = self.atas
        self.atas = node_baru

    def pop(self):
        if self.atas is None:
            return "Stack kosong"
        data = self.atas.data
        self.atas = self.atas.berikutnya
        return data

    def peek(self):
        if self.atas is None:
            return "Stack kosong"
        return self.atas.data

    def kosong(self):
        return self.atas is None

    def tampil(self):
        sekarang = self.atas
        while sekarang:
            print(sekarang.data, end=" -> ")
            sekarang = sekarang.berikutnya
        print("None")

stack_saya.tampil()

def parenthesesCheck(strMath):
    kurung = {')': '(', '}': '{', ']': '['}
    kurungBuka = kurung.values()
    kurungTutup = kurung.keys()
    temp = [] 
    
    for ch in strMath:
        if ch in kurungBuka:
            temp.append(ch)
        elif ch in kurungTutup:
            if len(temp) == 0:
                return 'Kelebihan Kurung Tutup'
            tempKurung = temp.pop()
            if tempKurung != kurung[ch]:
                return 'Tidak Cocok kurungnya'
                
    if len(temp) > 0:
        return 'Kelebihan Kurung Buka'
        
    return 'OK'

print(parenthesesCheck("(2 + 3) * {4 / [1 - 2]}")) 
print(parenthesesCheck("(2 + 3"))                  
print(parenthesesCheck("2 + 3)"))

class Stack:
    def __init__(self):
        self.data = []

    def push(self, item):
        self.data.append(item)

    def pop(self):
        if not self.isEmpty():
            return self.data.pop()
        return "Stack kosong"

    def peek(self):
        if not self.isEmpty():
            return self.data[-1]
        return "Stack kosong"

    def isEmpty(self):
        return len(self.data) == 0

    def size(self):
        return len(self.data)

def cek_kurung(expr):
    stack = []
    pasangan = {')': '(', '}': '{', ']': '['}

    for char in expr:
        if char in "({[":
            stack.append(char)
        elif char in ")}]":
            if not stack or stack.pop() != pasangan[char]:
                return "Tidak seimbang"

    return "Seimbang" if not stack else "Tidak seimbang"

print(cek_kurung("(3 + [2-1])"))
